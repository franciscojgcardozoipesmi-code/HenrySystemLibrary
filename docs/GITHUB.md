# Publicación en GitHub
La consigna pide repositorio y enlace para el docente @joselut. Ese paso requiere tu cuenta y todavía no se realizó.

1. Creá un repositorio vacío en tu GitHub, por ejemplo `henry-system-library`.
2. Desde esta carpeta, con Git instalado:

```bash
git init
git add .
git commit -m "Sistema de biblioteca y prestamos"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/henry-system-library.git
git push -u origin main
```

Reemplazá TU_USUARIO por tu usuario real. Si el repositorio es privado, invitá al docente `joselut` desde Settings → Collaborators. Si es público, entregá el enlace en Aula Virtual según indique el docente. No incluyas datos personales reales de estudiantes.
